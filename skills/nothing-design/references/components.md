# Component Patterns

Use spacing before containers: proximity groups related content, a single divider separates repeated rows, and a surface is reserved for controls or dense data. Use technical buttons with 4–8px radius or pills for primary actions; never use decorative rounded cards for the hero element.

For dashboards, use one hero metric, segmented progress or a compact bar for secondary metrics, and mono labels for metadata. Status color belongs on the value, not the entire row. Loading is inline text such as `[LOADING...]`; errors are inline `[ERROR: message]` rather than toast notifications.
