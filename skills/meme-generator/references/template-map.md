# Meme Template Map

- comparison: `drake`, `pooh`
- three-way tension: `db`
- denial: `fine`
- hot take: `cmm`
- realization: `astronaut`, `right`
- dilemma: `ds`, `exit`
- escalation: `gb`, `vince`, `gru`
- misidentification: `pigeon`

Encode spaces as `_`; literal `_` as `__`; `?` as `~q`; `!` as `~e`; `&` as `~a`; `/` as `~s`; newline as `~n`. Use `_` for a blank line. Download PNG and inspect before delivery.
